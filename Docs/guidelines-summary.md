# Hackathon Guidelines Summary — Kane CLI Hackathon by TestMu AI

**Source:** https://www.kaneclihack.sh/
**Fetched:** 2026-11-13 (Friday)

## Core Challenge
Build an app, an agent, or a workflow with an AI coding agent, on web or mobile. Verify it with Kane CLI. Ship by 11:59 PM IST on 19 November 2026.

## Key Dates
| Event | Date / Time |
|-------|-------------|
| Kickoff / building starts | Thu 12 Nov 2026 |
| Submission deadline | Thu 19 Nov 2026, 11:59 PM IST (10:29 AM PT) |

## Eligibility
- Anyone 18 or older, anywhere in the world
- Solo or teams of up to four
- No application, no cap
- Repo must be initialized on or after 12 November 2026 (commit history is checked)
- Must be signed up on testmuai.com and must have run Kane CLI to be eligible
- Employees of TestMu AI and participating partners are not eligible

## Tech Restrictions / Stack
- Any agent, any stack (Claude Code, Cursor, Copilot, Codex, Windsurf, Kiro, or own MCP setup)
- Kane CLI is the only requirement
- One submission per team; team captain receives the prize

## Submission Deliverables (5 items, all required unless noted)
1. **GitHub URL** — public repo, initialized on or after 12 Nov 2026
2. **About your app** — what you built, which agent, what Kane does
3. **Demo video** — hosted on YouTube, about 3 to 5 minutes
4. **Live URL** — if deployed (optional)
5. **Launch buzz** — at least two public posts (Hacker News, X, Reddit, LinkedIn); more posts = brownie points

## Judging Criteria
**Three bars (must clear all three to be scored):**
1. It works end to end (a real flow, not slides)
2. Kane CLI caught or proved something
3. Your agent and Kane CLI talked to each other (closed loop)

**Four dimensions (weighted equally, 25% each):**
1. Ships (25%)
2. Verified (25%)
3. Closed loop (25%)
4. Craft (25%)

Scores are averaged. Ties break on Verified, then Closed loop.

## Prizes
- 1st: $1,500 cash + $250 OpenAI credits
- 2nd: $1,000 cash + $250 OpenAI credits
- 3rd: $500 cash + $250 OpenAI credits
- Winners also: 1:1 with founders, 3 months Kane CLI Pro, featured blog post
- Every team that ships: Verified with Kane CLI badge
- Every team that submits: participation certificate

## Before You Start (mandatory)
1. Register on TestMu AI, then claim 10,000 free credits (required to be scored; use same email on both)
2. Install Kane CLI: `npm install -g @testmuai/kane-cli` and run one flow

## Data / Security Rules
- Hand over working credentials for any login or paid service
- Include a fallback (recorded run or backup deploy) for third-party services
- Demos do not have to be live — everything is a recorded YouTube video (3-5 min)
- Code stays yours; by submitting you grant TestMu AI permission to feature your project in marketing with attribution
- Code of Conduct applies throughout the hackathon (Slack and all event channels)
