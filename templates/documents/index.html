Closed-Loop Verification Architecture

Kane CLI ⟷ Coding Agent

1. Test Execution: Kane CLI verifies live page state in real Chrome: kane-cli run "Go to http://localhost:8000, verify the total shows ₦12,500" --agent --headless

2. Evidence Capture: If assertion fails (e.g. planted bug formats ₦1,250), Kane captures logs & screenshots.

3. Coding Agent Self-Correction: The coding agent parses the failure, fixes documents/services.py, and reruns Kane CLI until pass (code 0).
